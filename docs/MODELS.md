# Модели и параметры Bedrock

Все числовые ограничения ниже задаёт мастерская, а не полный формат Minecraft.

| Что редактируется | Поддержка                                                                      |
| ----------------- | ------------------------------------------------------------------------------ |
| Геометрия         | Bedrock Geometry 1.12.0, одна кубическая геометрия, до 256 костей и 2000 кубов |
| Кости             | Имя, родитель, pivot, поворот; циклы и повторяющиеся имена отклоняются         |
| Кубы              | Положение, размер, pivot, поворот, inflate, зеркальная UV-развёртка            |
| UV                | Общая box-развёртка или координаты отдельных граней                            |
| Отображение       | Границы видимости, масштаб 0,25–3, alpha test / alpha blend                    |
| Текстура          | PNG до 2048×2048; размер совпадает с texture_width/texture_height              |
| Анимация          | Простая ходьба для костей leg_*; для собственной модели включается отдельно    |
| Физика            | Размер столкновений, гравитация, толкание и прыжок                             |

16 единиц геометрии соответствуют одному блоку. Размер столкновений задаётся отдельно от формы кубов. Фигура игрока высотой 1,8 блока служит ориентиром и не меняет размер при изменении монстра.

В редакторе модели выберите кость и куб списками или щелчком в 3D. Доступны добавление, удаление, дублирование, экспорт `.geo.json` и до 40 шагов отмены в текущем сеансе. Открытие другого проекта сбрасывает историю отмены.

Для встроенной модели и моделей с палитрой работают поля цвета. У импортированного PNG без палитры цвет задаёт сама текстура: измените PNG и загрузите заново. Импортированная геометрия не получает шаблонные анимации автоматически.

Генерация возвращает до 32 костей, 240 кубов и восемь цветов. Полученная геометрия проверяется тем же валидатором. Редактора произвольных keyframe-анимаций, polygon mesh и рисования текстур здесь нет; для них используйте Blockbench.

[Справочник геометрии Microsoft](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/visualreference/geometry.v1.12.0?view=minecraft-bedrock-stable).
