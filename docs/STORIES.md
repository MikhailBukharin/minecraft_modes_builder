# Истории и диалоги

Вкладка «Истории и диалоги» содержит холст со связями. «Добавить готовый пример…» предлагает повтор и реплики, разговор и прогулку, торговлю, приказ идти к костру, помощь целителя, проверку хлеба и случайные слухи.

| Блок                  | Действие                                                                       |
| --------------------- | ------------------------------------------------------------------------------ |
| Начать                | Единственная точка входа                                                       |
| Сказать               | Реплика инициатору и пауза                                                     |
| Выбрать реплику       | Случайная фраза и пауза                                                        |
| Диалог с ответами     | Окно с 1–6 вариантами ответа                                                   |
| Открыть торговлю      | Настроенный обмен; выходы успеха и отказа/ошибки                               |
| Идти к ориентиру      | Путь к ближайшему костру, колоколу, сундуку или верстаку; прибытие или неудача |
| Стоять на месте       | Остановка на указанное время                                                   |
| Посмотреть на игрока  | Однократный поворот к инициатору                                               |
| Проверить предмет     | Проверка количества предметов в инвентаре; ничего не забирает                  |
| Случайная развилка    | Вероятностный переход «Да/Нет»                                                 |
| Восстановить здоровье | Лечение игрока или монстра до его максимума                                    |
| Наложить эффект       | Регенерация, скорость, сопротивление, огнестойкость или ночное зрение          |
| Проиграть звук        | Один из четырёх встроенных звуков инициатору                                   |
| Сообщение на экране   | Заголовок и подзаголовок инициатору                                            |
| Подождать             | Пауза без смены режима движения                                                |
| Следовать за игроком  | Наземное следование на заданное время                                          |
| Гулять рядом          | Случайная наземная прогулка на заданное время                                  |
| Повторить             | Отдельная цепочка 1–10 раз                                                     |
| Вернуться из повтора  | Конец тела повтора                                                             |
| Завершить             | Конец истории и восстановление обычного поведения                              |

Нажмите выход справа, затем вход слева у следующего блока. У каждого выхода может быть одна связь. Щелчок по линии удаляет её. Соедините все ответы и обе ветки условий. Тело повтора должно возвращаться, основная цепочка — завершаться. Обычные циклы и недостижимые блоки не допускаются при экспорте; незавершённый черновик можно сохранить.

Ограничения: 20 историй на проект, 100 блоков и 250 связей на историю, 2000 шагов выполнения и глубина повторов 8. Проверка в браузере ускоряет ожидания; ответы и условные результаты выбираются кнопками в журнале под холстом.

Движение использует AI Bedrock. Поиск ориентира — 1–24 блока, высота ±4, время пути — 1–60 секунд. Нужен проходимый загруженный участок. При отмене или истечении времени временная цель снимается. Координаты XYZ этим блоком не задаются. Чтобы существо осталось у ориентира, добавьте ожидание до завершения истории.

Лечение добавляет 1–100 HP и не воскрешает. Эффекты ограничены 1–60 секундами и уровнями I–III. Проверка предмета учитывает тип и количество, а не зачарования или состав зелья.

Историю запускают из меню взаимодействия в игре. Один игрок управляет движением существа; одна история выполняется на экземпляр. Закрытие диалога прерывает её, закрытие магазина ведёт по отрицательной ветке. При недоступности существа, другом измерении или удалении игрока дальше 32 блоков выполнение прекращается при ближайшей проверке. Открытое игровое окно проверяется после ответа/закрытия. Прогресс истории после перезагрузки мира не продолжается.

Для первых проверок выберите мирный характер: бой действует отдельно от истории. Произвольные команды из текстов блоков не выполняются.
